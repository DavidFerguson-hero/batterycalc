# BatterySizer frontend

The Next.js website for [batterysizer.co.uk](https://www.batterysizer.co.uk). See the [main README](../README.md) for what the project is, how to run it, test it and deploy it.

```bash
npm install
NEXT_PUBLIC_API_URL=http://localhost:8000 npm run dev   # http://localhost:3000
```

Use `NEXT_PUBLIC_API_URL=https://batterysizer-api.onrender.com` to work against the live API instead of a local one.
